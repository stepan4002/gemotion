# GEMOTION Academy

Webstránka pre **GEMOTION Academy — Športovú školu Miloša a Inga**, systematický program všeobecnej športovej prípravy pre deti vo veku 6 až 11 rokov v regióne Rožňava.

## Obsah

- `index.html` — kompletná jednostránková webstránka v slovenčine
- `gemotion logo.png`, `gemotion icona.png` — logo a ikona
- `WhatsApp Image *.jpeg` — fotografie z tréningov, kempov a športových dní
- `WhatsApp Video *.mp4` — video použité v hero sekcii
- `Športová škola_GEMOTION.pdf` — zdrojový dokument s textami projektu

## Spustenie

Stránka je statická – otvor `index.html` v prehliadači alebo nasaď na ľubovoľný hosting.

## Projekt

Projekt vzniká pod záštitou **TJ Geológ Rožňava**.
